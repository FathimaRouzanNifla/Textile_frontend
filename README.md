# Mubarak Textiles — Premium Fashion & Lifestyle Website

A modern, elegant, and fully responsive multi-page website for **Mubarak Textiles**, a fashion and textile store located in Sainthamaruthu, Sri Lanka.

The website showcases fashion collections for women, men, kids, bridal, abaya, traditional wear, and home textiles through a premium editorial-inspired user experience.

## ✨ Project Overview

Mubarak Textiles brings fashion and lifestyle collections together in a sophisticated digital experience.

The website focuses on:

- Premium UI/UX design.
- Elegant editorial layouts.
- Interactive category mega menus.
- Dedicated collection pages.
- Smooth animations and transitions.
- Responsive layouts across devices.
- Direct customer communication through WhatsApp and telephone.
- Google Maps store location integration.

**Project Type:** Multi-page frontend website  
**Business Category:** Fashion & Textiles  
**Design Direction:** Modern Luxury / Editorial Fashion  
**Status:** Frontend Showcase Website

## ⚙️ Installation and Setup

### Prerequisites

- Node.js (LTS version recommended).
- npm, yarn, or pnpm.
- Git.

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the Project

```bash
cd mubarak-textiles
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

```text
http://localhost:3000
```
